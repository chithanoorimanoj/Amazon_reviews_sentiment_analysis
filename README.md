# Amazon Customer Review Sentiment Analysis

## Project Overview
Developed an end-to-end NLP and Machine Learning application to analyze Amazon customer reviews and classify their sentiment into three categories: **Positive, Neutral, and Negative**.

The project uses NLP techniques and Logistic Regression to understand customer opinions and generate sentiment predictions.

## Technologies Used
- Python
- NLP
- NLTK
- TF-IDF
- Scikit-learn
- Logistic Regression
- Streamlit
- Joblib

## Key Features
- Text preprocessing using NLTK.
- TF-IDF feature extraction.
- Sentiment classification using Logistic Regression.
- Prediction confidence scores.
- Interactive Streamlit application.
- Joblib model integration.

## Project Workflow
1. Customer review collection.
2. Text cleaning and preprocessing.
3. TF-IDF feature extraction.
4. Model training using Logistic Regression.
5. Sentiment prediction.
6. Streamlit application deployment.
